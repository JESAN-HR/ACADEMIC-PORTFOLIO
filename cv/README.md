# Your academic CV

Place your updated CV PDF here and name it exactly **JESAN.pdf**.

Then double-click `build-portfolio.cmd` in the main project folder (or run `npm run build`) and refresh the website. The hero's Download CV button will activate, and the PDF will be copied to `dist/cv/JESAN.pdf` for deployment.

Until the PDF exists, the button says Download CV but is disabled with a “CV will be available soon” note. No placeholder or outdated CV is served. To replace your CV later, overwrite JESAN.pdf and rebuild.
